Behind the destinations

Each country has its own background photo. This connected prototype uses the original online photos. A local loading preview is bundled. Run tools/fetch_assets.py, then tools/build_prototype.py --offline from the handoff root to embed all six photos.

    Look around adds a constrained pan, zoom, and perspective effect to a flat photograph. It is not a 360° panorama or a reconstructed 3D scene. A small crop of the supplied reference image is included as the initial Philippines loading preview. The reference and this preview are not cleared production photography. The morph uses procedural texture displacement, not landmark tracking or true 3D geometry. Photo shaders need WebGL and cross-origin image permission; otherwise the original crossfade remains available.
