# Reference hierarchy

`original-user-reference.png` is the exact original inspiration image. It contains overlaid words and a logo; those are not reusable app assets or a correct country dataset.

`layout-desktop-preview-only.png`, `layout-mobile-preview-only.png` and `card-preview-only.png` are browser captures of the approved HTML card. They use the available Philippines loading crop as a temporary capture source. They are layout references, not final photographic or typography approval. The six full-size online originals were unavailable to the packaging environment.

The working prototype is the authority for motion. The shader source defines the effect. The later AI-generated dark/glass mockups are not part of this rebuild direction and are not packaged. QA's synthetic textures and any QA captures must not be copied into production assets or treated as destination imagery.

Read `capture-metadata.json` for exact viewport/source information. Re-capture with all full-size photos after the asset download succeeds.
